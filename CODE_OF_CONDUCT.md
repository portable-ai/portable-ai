# Code of Conduct

PortableAI is intended to be a welcoming, constructive project.

Participants are expected to:

- Be respectful.
- Assume good intent.
- Discuss ideas, not personalities.
- Avoid harassment, discrimination, or abusive behavior.
- Protect personal privacy.

Because this project concerns personal context and AI identity, contributors should be especially careful with examples, test data, and discussions involving real people.

Project maintainers may remove comments, issues, pull requests, or contributors that violate these expectations.

# docs/archive

Frozen historical documents — planning snapshots, audits, and point-in-time
decision context that we want to preserve but **not** maintain as living docs.

Unlike `adr/` (living, current Architecture Decision Records) or top-level project
docs, everything here is a **frozen record**: it captures the state and reasoning at a
specific date and is not updated afterward. Each file should carry its own date and be
treated as read-only history.

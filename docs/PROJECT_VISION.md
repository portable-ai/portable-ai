# Project Vision

Portable AI exists to help people own and carry their AI context across systems.

As AI assistants become more useful, they learn more about how people think, work, decide, and communicate. Today, that context usually lives inside a vendor-specific system.

Portable AI starts from a different premise:

> People should own their context.

## The first standard

The first standard is the Portable AI User Model: a single, human-readable Markdown document containing durable information about a person.

The document may include preferences, projects, interests, communication style, decision style, and instructions for AI collaboration.

## What this is not

Portable AI is not trying to be:

- A social network
- A cloud storage platform
- A proprietary identity provider
- A replacement for AI memory systems
- A personal data warehouse

## What success looks like

Success means a person can maintain one readable profile and use it across AI systems, editors, tools, and workflows without starting over each time.

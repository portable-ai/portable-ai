# Contributing

Thank you for your interest in Portable AI.

This project is in early draft form. Contributions should preserve the core principles:

- Human-readable first
- One canonical Markdown document
- Vendor neutral
- User owned
- Simple before clever

## Ways to contribute

- Improve the spec
- Improve examples and templates
- Build or refine the reference editor
- Propose AI-specific export formats
- Improve documentation

## Contribution process

1. Open an issue describing the change.
2. Discuss the proposed direction.
3. Submit a pull request.
4. Keep changes focused and reviewable.

## Spec language

When editing the spec, use requirement words consistently:

- MUST
- MUST NOT
- SHOULD
- SHOULD NOT
- MAY

## Personal data

Do not submit private, sensitive, or personally identifying profile data unless it is clearly fictional or intentionally public.

Ask an AI to draft one

Send the prompt below to any AI assistant you already use. It will reply with a Markdown profile you can paste back into the editor, or save as a file and open on PortableAI.org.

  1. Open an AI assistant you already use.
  2. Copy the prompt below and send it in that AI.
  3. Save the Markdown result as a file, or copy the text.
  4. Come back to PortableAI.org to review or make changes, or load the Markdown into a new AI.

PortableAI does not connect to your AI accounts or send this prompt anywhere. Copying, reviewing, pasting, loading, and downloading all happen in your browser.
